níveis de dificuldade** e **CPU com lógica básica de IA**.

Projeto feito em **Python puro** 🐍 --- ideal para estudar lógica de
programação.

## 📌 Funcionalidades

-   Interface em ASCII no terminal\
-   Jogador vs Computador\
-   3 níveis de dificuldade\
-   Modo memória (esconde jogadas antigas)\
-   CPU que tenta vencer e bloquear\
-   Loop de partidas

------------------------------------------------------------------------

## ▶️ Como executar

``` bash
git clone https://github.com/EdcleyVitor/JogoDaVelha.git
cd JogoDaVelha
python jogo.py
```
